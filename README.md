# MovieExplorer

A responsive, interactive web application built with **React**, **React Router DOM**, **Tailwind CSS**, and **DaisyUI**. Users can explore popular TV shows and movies, perform real-time searches, and view detailed information in an interactive modal view powered by the **TVMaze API**.

## Tech Stack

- **Frontend:** React 19, JavaScript (ES6+)
- **Routing:** React Router DOM v7
- **Styling:** Tailwind CSS v4, DaisyUI v5
- **API:** [TVMaze API](https://www.tvmaze.com/api)
- **Build Tool:** Vite
